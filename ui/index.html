    Getting an Application ID

    1. Open the Discord Developer Portal → New Application.
    2. Its name is what shows after "Playing" (or "Listening to", "Watching", "Competing in") — so call it whatever you want people to read: Life, the grind, nothing… Make several and switch per preset with the override field.
    3. Copy the Application ID from General Information and add it under Manage in the top bar — the name fills in by itself.
    4. Images: paste any https:// image link, or upload art under Rich Presence → Art Assets and type the asset key — keys show up as suggestions once the ID is set.

    Nothing here touches your account token: the app talks to your running Discord client over its local Rich Presence pipe, exactly like a game would.

    Applications

    Each Discord application is one headline — its name is what shows after "Playing". Create them in the Developer Portal, paste the Application ID here; the name fills in automatically.
