# Keyboard shortcuts

| Keys | Action |
|---|---|
| `Ctrl` + `Enter` | Apply the selected preset |
| double-click a preset | Apply it |
| `Ctrl` + `N` | New preset under the current application |
| `Ctrl` + `D` | Duplicate the selected preset |
| `Delete` | Delete the selected preset (when not typing in a field) |
| `Ctrl` + `↑` / `Ctrl` + `↓` | Move the selected preset up / down |
| `F1` | Open this wiki |
| `Esc` | Close any dialog |

`Cmd` stands in for `Ctrl` on macOS.

Tray: left-click the icon to open the window; right-click for the menu (apply presets, start or
stop rotation, clear, quit).
